How it works
Connecting an account grants Snarelytics read + quarantine access to that inbox via the provider's own OAuth sign-in (nothing is stored except an access token — never your password). Once connected, both the Inbox and Spam/Junk folders are checked automatically every ~90 seconds using the same detection pipeline as manual scans, regardless of which provider the account is on. Anything scored Phishing is moved into a Snarelytics Quarantine folder/label — reversible any time from the mail provider directly, or from the Quarantine page here.

Note on Spam/Junk: mail providers typically already filter most phishing into Spam using their own authentication checks before Snarelytics ever sees it — scanning that folder mainly surfaces what was already caught, rather than catching something that was missed.

First-time setup on the server (a developer account + OAuth credentials with the provider) is a one-time step per provider — see SETUP_GMAIL.md or SETUP_OUTLOOK.md in the project folder if a "Connect" button shows an error.
